Count

File naming

mapping needs them added.

Format

may need resizing or cropping to match before upload.

Notes
All photos are AI-generated. The people are characters, not real workers or Circle users.
Each was checked by eye for nudity, invented lettering, black borders, cut-off heads and soft faces.
